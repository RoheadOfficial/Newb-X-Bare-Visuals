# B0.2.2 Baseline Notes and B0.2.5 Follow-up

## Goal

Replace the underwhelming B0.1.9 visual result with a stronger, cohesive Overworld style and restore the broader Newb X Legacy Always Reflection idea while keeping performance a first-class requirement.

**Current status:** B0.2.2 has been pushed to `main`. The Android CI build and artifact upload passed, and the creator tested it in Minecraft. The reported result is that the overall look needs major improvement, performance needs more work, and the reintroduced terrain-shading code did not produce a noticeable difference. These findings are being used to plan B0.2.5.

## Visual direction

- Original warm, natural, semi-realistic vanilla lighting inspired by Newb Tropisphere's published visual direction.
- Restrained saturation, warm daylight and dawn, cooler night colors, natural sky gradients, and atmospheric fog/rain.
- Better perceptible terrain depth without excessive darkening or oversaturation.
- The reference is visual inspiration only; this implementation does not copy Tropisphere's shader source.

## Player-facing subpacks

Exactly two subpacks are configured in this order:

1. **Lite — Box Clouds, Legacy Reflections & Reduced Effects**
2. **Default — Box Clouds, Always Reflection & Full Atmosphere**

Both use the parent's `BOX_CLOUDS` implementation. Default is right-most in the manifest list and is expected to be the initial selection; confirm in the generated pack and in Minecraft. Soft Sunlight, Misty Mornings, Golden Hour, Rounded Clouds, Realistic Clouds, and Render Anim are not selectable in B0.2.2.

Lite preserves the core Always Reflection concept but reduces reflection distance and selected secondary effects. Plant and lantern movement remain enabled at reduced amplitude. Water waves and displacement remain disabled.

## Always Reflection

- Water currently uses the existing Newb sky-reflection path with a flat normal (`NL_WATER_BUMP = 0.0`) and no `NL_WATER_WAVE` displacement. B0.2.5 plans to remove the Always Reflection treatment from water.
- Horizontal terrain receives restrained always-on sky reflection.
- Rain continues to strengthen the wet-ground reflection and puddle variation.
- Aurora visuals remain enabled at reduced intensity in Lite; aurora reflection detail is disabled in Lite to reduce work. The parent reflection function does not reconstruct box-cloud geometry, so cloud reflections are not promised.
- Reflection distance is limited by `NL_GROUND_REFL_DISTANCE` and an absolute maximum of 56 blocks in Default / 32 in Lite.
- The current parent reflection code supports sky/aurora details; box-cloud geometry itself is not guaranteed to be reflected. This limitation must not be hidden in release claims. Aurora is the deliberate Legacy tribute exception; rainbows, shooting stars, galaxy stars, and godrays remain excluded, and the original Newb sky pipeline is retained.

## Selective terrain shading

The community snippet's intent is preserved, but repeated independent threshold multipliers are replaced with a single smooth, bounded ramp using the green vertex-color channel. This avoids cumulative darkening when many thresholds match the same fragment. The alpha-zero branch is retained as a capped correction, and the original red/green-channel condition is retained at reduced strength.

The correction is confined to `RenderChunk` and skips transparent materials and seasonal materials. Actor shaders are unchanged, so this custom pass does not add player or mob shadows. It is a terrain color/shading correction rather than a shadow-map implementation.

## B0.2.5 implementation status

- Current branch: `b0.2.5-implementation`; main remains untouched.
- Display label B0.2.5; numeric manifest version `[0, 16, 61]`; inspect generated manifest after CI.
- Subpack order: Lite #1, Beta #2, Default #3.
- Active cloud type set to rounded clouds (`NL_CLOUD_TYPE 2`).
- Default's configured weather overlay reduced from 0.35 to 0.3465, a 1% relative reduction.
- Water's `NL_CLOUD_AURORA_REFLECTION` toggle disabled; terrain reflection remains separate.
- Rounded-cloud alpha fades at night; configured aurora intensity increased.
- Base saturation and lighting values adjusted toward restrained, softer colors.
- Beta currently has experimental lightmap-driven torch-response and terrain contact-shading prototypes. These are not full dynamic-light injection, true indoor reflections, or shadow maps.
- No active godray toggle was found in config; source review and CI remain necessary.
- CI build, generated manifest inspection, and in-game performance/visual tests are pending.
- Continue investigating the B0.2.2 terrain correction because it was not visibly effective in the creator's test.
