# B0.1.9 Implementation Notes

## Release objective

Deliver five purposeful profiles, visibly distinct lighting/atmosphere, a clean subpack list, accurate build metadata, and measurable performance improvements without claiming zero lag before device testing.

## Player-facing subpacks

The manifest is configured in this requested order:

1. **Default — Realistic Clouds · Balanced Visuals**: baseline profile using cloud type 3.
2. **Soft Sunlight — Warm Light, Soft Nights & Rain**: softer direct light, warm-neutral daylight, a distinct dusk palette, cool night sky, restrained mist, and cool-clear water tint.
3. **Misty Mornings — Visible Mist, Rain & Cool Nights**: higher distance mist, stronger rain mist, a muted sky, and coordinated night/rain/water colors.
4. **Golden Hour — Amber Light, Rain & Cool Nights**: warm daylight and dawn/dusk lighting, cool nighttime palette, and restrained rain/mist.
5. **Lite — Rounded Clouds & Reduced Effects**: cloud type 2, no plant/lantern movement, no glow shimmer, lava noise, rain-speck styling, shooting stars, aurora, rainbow, cloudy fog, underwater streaks, or entity edge highlighting; terrain fragments also skip the extra glow texture sample.

The previous Render Anim option is removed from the active subpack list. Its compile-time macro remains in source but is not shipped as a selectable option.

Minecraft's subpack manifest supports a display name but no separate per-option description field. Therefore each displayed subpack name includes a concise description of its identity.

## Weather, day/night, and water

Each atmospheric profile has compile-time overrides for the sunlight tint/intensity, dawn palette, day palette, night palette, rain sky colors, fog/mist behavior, and water tint. The current shader exposes day/rain environment values but no verified direct clock-hour switch for an independently scheduled morning-only mist. Misty Mornings therefore means a mist-focused profile that remains active outside morning too, rather than pretending it detects a unique morning window.

Water improvements use the existing vanilla-water fragment path and preserve engine transparency/fog. No custom waves, displacement, or new reflection pass is added.

## Performance strategy

- Keep cloud shadows disabled.
- Reduce the plant/lantern wave range from 13 to 9 blocks.
- Use Lite's rounded cloud renderer instead of the realistic cloud renderer.
- In Lite, skip the glow texture sample on every terrain fragment.
- Disable optional effects in Lite that add shader work without being essential to the base terrain appearance.

These changes target avoidable shader cost. They do not control Minecraft's chunk generation, device thermals, RAM pressure, or all rendering bottlenecks; zero lag is not guaranteed.

## Known limitations

- GitHub Actions verifies compilation/artifact generation, not in-game appearance or mobile FPS.
- Minecraft subpack defaults and visual order must be checked in the generated pack and on device.
- The realistic cloud renderer is more computationally involved than rounded clouds; Lite exists as the performance-oriented choice.
