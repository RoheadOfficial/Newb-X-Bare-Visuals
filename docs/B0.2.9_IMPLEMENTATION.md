# B0.2.9 Implementation Notes

## Branch and scope

Implementation branch: `b0.2.9-implementation`  
Planning branch: `b0.2.9-plans`  
Target version: B0.2.9 / manifest 0.2.9

Changes remain isolated from `main`. The purpose is to reduce unnecessary work in large terrain views without removing most of the shader's visual features.

## Source changes

### Terrain reflection

The existing reflection distance cap remains the primary spatial limit. Reflection cosine and blend-strength calculations are moved behind the horizontal-plane condition, because those values are only consumed by the reflection result. Puddle variation still feeds the wet-ground darkening path. The reflection blend retains its previous pre-puddle wetness contribution where that matters, so this change should not silently alter the intended wetness model.

### Glow

Default retains the local emissive halo and shimmer. The halo uses four cardinal taps; unused corner-sample declarations are removed. Lite continues to skip the extra terrain glow calculation.

### Rounded clouds and aurora

Default keeps four rounded-cloud density samples. Lite uses three. The aurora function exits during daytime when the current output mask is exactly zero; twilight/night calculations and colors are retained.

### Profile compilation

The pack builder compiles the root material set using the `DEFAULT` define, so Default-specific settings are active in the base materials. Lite compiles the full material list separately with `LITE`. The Default subpack stays empty to inherit root materials without duplicating shader binaries; Beta remains an empty experimental slot.

### Weather, fog, and entities

Rain particles, rain mist, cloudy fog, and wet-ground response are preserved. No new entity shadows are added. Actor shaders remain outside the terrain-specific changes.

## Automated checks

`tool/validate_b029.py` checks version alignment, subpack order, profile material lists, protected features, optimization anchors, and workflow/artifact labels before builds begin.

## Manual verification still required

- Android and multiplatform build success
- Generated manifest and artifact inspection
- Profile selection and compiled material verification
- Comparable large-terrain performance tests on the target device
- Rain, wet ground, fog, rounded-cloud, aurora, and glow visual checks

Do not describe the update as zero-lag or fully accepted until those checks have been performed.
