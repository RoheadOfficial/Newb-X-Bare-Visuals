# B0.3.3 — Cozy Atmosphere Redesign

## Status

Implementation is in progress on `b0.3.3-cozy-atmosphere`, based on the B0.3.2 merge on `main`. Static validation has passed in the current GitHub Actions run. Shader builds and in-game visual/performance acceptance are still pending.

## Design goal

B0.3.3 responds to the B0.3.2 in-game feedback that Default, Bare Visuals, and Pootaytoe still looked almost unchanged from the previous version. The update prioritizes a cozy atmosphere through coordinated changes to the active sky, lighting, fog, and rounded-cloud shader paths. Prizma Visuals is a mood reference, not a source to copy.

## Source changes

- `src/newb/config.h`: added compile-time cozy-atmosphere controls for sky, ambient lighting, fog, and rounded-cloud softness. Default uses balanced values, Bare Visuals expresses the mood more strongly, and Pootaytoe keeps a lighter blend.
- `src/newb/functions/sky.h`: added a restrained warm horizon lift and a broader soft horizon band to the rendered Overworld sky.
- `src/newb/functions/lighting.h`: added a subtle warm-neutral daylight lift and increased sky-horizon contribution to terrain and entity ambient lighting.
- `src/newb/functions/fog.h`: introduced profile-aware distance haze and a slightly earlier clear-weather fog transition while retaining rain-aware fog.
- `src/newb/functions/clouds.h`: added a small horizon-side fill to rounded-cloud shading without adding texture reads or ray samples.
- `src/newb/pack_config.toml`: bumped the manifest version to `[0, 3, 3]` and the development label to `B0.3.3`.
- `tool/pack.py`: updated the fallback development version.
- `tool/validate_b033.py`: added static checks for the B0.3.3 version, profile controls, rendering paths, and existing safeguards.
- `.github/workflows/build.yml` and `.github/workflows/build-check.yml`: updated version defaults, artifact labels, validator calls, and the implementation branch trigger.
- `Plans.md` and `CHANGELOG.md`: recorded the redesign goals and pending verification.
- `tool/validate_b032.py` remains unchanged.

## Preserved constraints

- No godrays, Always Reflection water, water waves, tree waving, box clouds, or custom player/mob shadows.
- Vanilla-like water, rain particles, rain atmosphere, and wet-ground behavior remain in place.
- No extra render pass or additional cloud sampling was introduced by these changes.
- No claim of zero lag or confirmed in-game appearance is made before testing.
